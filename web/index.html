Block

Click a block to edit it.
Drag over an empty spot to add a block (a plain click adds 30 min).

A block's edge changes its length: if the neighbour touches it, you move the shared boundary; if there is a gap, you fill the gap first. The middle of a block moves the whole block and stops at the neighbour. Logged blocks (striped) are locked.

Del deletes · ⌘Z undoes · ←→ move by 5 min · Esc cancels

Import worklog

  
Paste the output of /worklog or a part of the file. A header like @Tuesday 27.10 (any weekday name) sets the day; without one the blocks go to the current day. Open blocks of that day are replaced, logged ones stay (⌘Z undoes).
